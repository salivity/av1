How AOMedia Handles Non-Member Contributions

The Alliance for Open Media (AOMedia) allows non-member organizations and individuals to submit technical feedback and code, provided they adhere to strict licensing frameworks that protect the royalty-free status of its technologies. To prevent patent hold-ups and intellectual property conflicts, AOMedia mandates that any external contributor execute a Contributor License Agreement (CLA) or submit input through designated public review periods before any contribution can be merged into official specifications or software projects.

Mandatory Contributor License Agreements (CLAs)

To safeguard open-source codecs like AV1, AOMedia requires all non-member contributors to sign an AOMedia Contributor License Agreement prior to submitting code, patches, or specification text. This agreement legally binds the contributor to the same royalty-free patent licensing commitments that govern regular members. Automated systems, such as CLA bots on AOMedia's public GitHub repositories, automatically check pull requests and block any external code from being integrated until a valid agreement is executed.

Public Working Drafts and Feedback Windows

Non-members can influence AOMedia standards during formal public review windows. When a working group advances a specification to a public draft status, outside organizations can review the documentation, report ambiguities, and propose changes via the alliance's issue trackers. While this allows external industry stakeholders to provide operational and architectural input, any substantive technical solutions offered during this phase remain subject to AOMedia's intellectual property terms.

Open-Source Software Participation

Beyond the core specifications, AOMedia maintains reference implementations and software libraries under standard open-source licenses, typically the BSD 2-Clause License combined with the AOMedia Patent License 1.0. Non-member organizations can contribute bug fixes, performance optimizations, and platform ports to these repositories. Acceptance depends on code quality, alignment with the specification, and clear patent clearances established by the licensing terms.

Limitations for Non-Members

While non-members can contribute technically, they do not have voting rights or governance influence within AOMedia Working Groups. Non-members cannot define the technical charter of a project, vote on the progression of draft standards, or participate in closed working group meetings. Organizations seeking direct influence over the strategic direction and final ratification of AOMedia standards must transition from outside contributors to formal members.
